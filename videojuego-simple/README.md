# Videojuego sencillo — Snake

Juego clásico de Snake hecho con HTML5 Canvas + JavaScript puro. Sin dependencias, sin build tools.

## Cómo jugarlo

Abre `index.html` directamente en cualquier navegador (doble clic, o "Abrir con navegador").

## Controles

- Flechas del teclado o WASD para moverte.
- Botón "Reiniciar" para volver a empezar tras perder.

## Estructura

Todo vive en un solo archivo (`index.html`): HTML, CSS y JS embebidos. Ideal como punto de partida para modificar reglas, velocidad, colores o agregar niveles.
